# personal-notes-manager-14198-14235

Django REST API for personal notes with user authentication.

Quickstart:
- Install dependencies from requirements.txt
- Apply migrations: python manage.py migrate
- Run server: python manage.py runserver 0.0.0.0:3001
- Docs available at /docs (e.g., http://localhost:3001/docs)

Environment:
- See notes_backend/.env.example for available variables (SECRET_KEY, DEBUG, hosts, DB settings).
